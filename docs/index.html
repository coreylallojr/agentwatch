Install Wizard

Welcome to the agentwatch Setup Wizard

Install in one line

The installer downloads the latest release for your system, checks its SHA-256, puts agentwatch on your PATH, then runs agentwatch setup to add the skills and MCP server to Claude Code. Restart Claude Code and you're done.

In PowerShell:

irm https://raw.githubusercontent.com/coreylallojr/agentwatch/main/install.ps1 | iex

Installs to %LOCALAPPDATA%\agentwatch\bin and adds it to your user PATH. No admin rights needed.

In a terminal:

curl -fsSL https://raw.githubusercontent.com/coreylallojr/agentwatch/main/install.sh | sh

Installs to ~/.local/bin (set AGENTWATCH_INSTALL_DIR to change it). Apple Silicon, Intel Macs and x86-64 Linux.

Inside Claude Code (bundles the skills and MCP server):

/plugin install agentwatch --marketplace coreylallojr/agentwatch

The plugin runs the agentwatch binary, so install it first with a one-liner and AGENTWATCH_NO_SETUP=1.

With a Rust toolchain:

cargo install --git https://github.com/coreylallojr/agentwatch agentwatch
agentwatch setup
Then
  1. agentwatch opens the dashboard for the project you're in.
  2. Ask Claude: "launch two agents to … and wait for them". It uses agentwatch_wait instead of polling.
  3. agentwatch status gives the same picture in your terminal.

Control Panel

Pick a category

  • Zero tokens

    Reads the transcripts Claude Code already writes. Watching costs nothing.

  • Live lanes

    Running, thinking, stale, stuck or done, for every subagent, updated in about 100 ms.

  • Every tool call

    Inputs, outputs, durations and screenshots, with long output trimmed head-and-tail.

  • Errors that make sense

    Each failure is recovered, unresolved, still working, or blocked by a hook.

  • MCP for your agents

    Claude waits for its own subagents and reads their timelines, without polling.

  • Private by default

    127.0.0.1 only, read-only, and emails, tokens and card numbers are masked.

  • Light

    One ~3 MB binary, about 50 MB of memory and under 1% of a core while idle.

  • Grows with you

    Agents log what they missed; a skill builds it on your fork and opens a PR.

For AI agents - MCP tools

Claude can watch its own agents

agentwatch setup registers an MCP server with Claude Code. Every tool returns short, redacted text, and transcript content is labelled as observed data, never instructions.

ToolWhat it's for
agentwatch_waitBlock until a subagent (or any, or all) finishes, changes or gets stuck. Returns their final reports.
agentwatch_statusEvery subagent in the current session: status, counts, latest activity.
agentwatch_agentOne agent's prompt, numbered timeline and final report. Paged, with a noise filter.
agentwatch_eventOne tool call's full input and output.
agentwatch_errorsFailures classified: recovered, unresolved, unknown, blocked-by-guard.
agentwatch_sessionsRecent sessions across all your projects.
agentwatch_snapshotThe whole session as text, for a full account.
agentwatch_dashboardStart the dashboard and return (or open) its URL.
agentwatch_suggest_improvementRecord what agentwatch couldn't do, in ~/.agentwatch/ideas.md.

It grows with you

  1. An agent hits a gap and records it
  2. agentwatch ideas lists it
  3. The agentwatch-evolve skill builds it on your fork, with tests
  4. You approve the push and the PR. Sharing upstream is optional.
Help and Support Center

Frequently asked questions

Does it send my transcripts anywhere?

No. It reads files under ~/.claude/projects on your machine and serves them to your browser on 127.0.0.1. Nothing leaves your computer, and it never writes to your transcripts.

Does watching cost tokens?

Collecting and showing data costs nothing. If you let Claude use the MCP tools, the text those tools return counts like any other tool result, which is why they return short summaries by default.

What do the statuses mean?

running: a tool call is in flight. thinking: waiting on the model. stale: idle for over 90 s. stuck: idle for over 240 s, often a permission prompt waiting on you. done: finished.

Is the redaction perfect?

No. It masks emails, SSNs, Luhn-valid card numbers, JWTs, bearer tokens, *_TOKEN=-style values and long hex or base64 secrets. That's best effort, so treat the dashboard as sensitive anyway.

How do I get notified about things?

Focus rules in ~/.agentwatch/rules.json highlight events or show a desktop toast, for example for browser automation, hook denials or stuck agents. See rules.json in the repo for the format.

How do I uninstall?

Run agentwatch stop, then claude mcp remove agentwatch --scope user. Delete the binary, ~/.claude/skills/agentwatch* and ~/.agentwatch.
